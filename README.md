# Jairus Jimenez — Developer Portfolio

Static editorial portfolio built with Tailwind CSS and vanilla JavaScript, featuring:
- **MMExpress — Service Center & POS** (`mm-express-ui`)
- **Tower System VTT — D&D Companion App** (`dnd-vtt`)
- **WHO CGS BMI & Growth Calculator** (`who-cgs-bmi-app`)
- Live GitHub repository feed from `https://api.github.com/users/jairusjimenez/repos`

## Free Hosting (GitHub Pages)
1. Push this folder to a GitHub repository named `jairusjimenez.github.io` (or any repo under `jairusjimenez`).
2. In the repository **Settings → Pages**, set **Source** to `Deploy from a branch` (`main` / `/root`).
3. Your site will be live at `https://jairusjimenez.github.io`.
